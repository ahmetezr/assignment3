# Assignment 3 — Task Manager with a Reducer

Ahmet EZER — 2200008227

Required assignment implementation, based on the supplied starter project.

## Run

Requires Node.js 20.19 or newer.

```text
npm install
npm run dev
```

Open the local address printed by Vite. Tasks are held in memory and reset on refresh.

## Build

```text
npm run build
```

This runs TypeScript in strict mode and creates the production build.
